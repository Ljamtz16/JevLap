Conectar Jev

  1. Abre TypeSafe Console y crea tu cuenta.
  2. Obtén una API key y revisa el plan de facturación.
  3. Configura TYPESAFE_API_KEY en el entorno del servidor.
  4. Importa un snapshot en el formato del ejemplo incluido.

La clave nunca se guarda en el navegador. Modelo solicitado: jev-1.13.0. Confianza mínima: 75%.

Preparado para la VPS
Servidor Python sin dependencias externas, base SQLite propia e interfaz local.
El worker consume snapshots de la VPS. El ejecutor usa una cuenta Alpaca paper exclusiva: un contrato y una posición abierta. Los snapshots antiguos no generan entradas paper.
